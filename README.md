# Учебная доска задач

Стартовый проект для модуля Redev AI agents. Это адаптивная React-доска с задачами в колонках «К выполнению», «В работе» и «Готово». Данные хранятся локально в браузере, поэтому с доской можно работать без сервера.

Поиск намеренно отсутствует: его вы добавите в ходе курса.

## Начало работы

Для работы нужны Node.js 22 и npm 10 или новее.

1. Нажмите **Use this template** на странице репозитория и создайте свой репозиторий.
2. Склонируйте созданный репозиторий и перейдите в его папку.
3. Установите зависимости:

   ```bash
   npm ci
   ```

4. Запустите приложение:

   ```bash
   npm run dev
   ```

Vite выведет в терминал локальный адрес, обычно `http://localhost:5173`.

## Команды

```bash
npm run dev       # запустить приложение в режиме разработки
npm test          # запустить тесты
npm run lint      # проверить код ESLint
npm run typecheck # проверить типы TypeScript
npm run check     # выполнить ESLint, проверку типов и тесты
npm run build     # собрать production-версию в dist/
```

Перед отправкой изменений выполните:

```bash
npm run check
npm run build
```

## Сброс демо-данных

В интерфейсе доски используйте действие «Сбросить данные» и подтвердите его. Оно вернёт исходные демонстрационные задачи.

Если приложение не открывается, удалите данные сайта для локального адреса в настройках браузера и перезагрузите страницу.
