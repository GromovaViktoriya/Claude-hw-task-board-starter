# Пример вызова `/pr`

**Механика:** динамический контекст. Скилл сам подставляет вывод shell-команд:

```
Дифф: !`git diff --staged`
Ветка: !`git branch --show-current`
```

**Вызов:** `/pr` (без аргументов), ветка `feature/overdue-counter`.

**Что подставилось:** `git diff --staged` вернул только новый пустой файл
`.claude/skills/pr/SKILL.md` — изменения задачи к этому моменту уже были
закоммичены. Поэтому описание составлено по фактическому диффу ветки
`git diff main...feature/overdue-counter` (5 файлов, +132/−61).

## Результат

## Счётчик «Просрочено» в статистике доски

### Что и зачем
- В блок статистики добавлен счётчик «Просрочено: N». Просроченной считается задача, у которой срок раньше сегодняшней **локальной** даты и статус не `done`. Задачи без срока и со сроком на сегодня в счётчик не попадают.
- `LegacyBoardStats` больше не читает `localStorage`. Все четыре показателя считаются из списка задач, который `TaskBoard` уже загрузил через `TaskRepository`, и приходят через props. Так требует правило в `CLAUDE.md`.
- Раньше статистика обновлялась только потому, что `TaskBoard` перерисовывался после записи в хранилище, а сам компонент повторял проверку формата хранилища. Теперь счётчики пересчитываются после создания, редактирования, перемещения, удаления и сброса без перезагрузки страницы.

### Что проверить в первую очередь
1. `isOverdue` / `toLocalDateKey` в `src/features/tasks/model/task.ts`. Даты сравниваются как строки `YYYY-MM-DD`. «Сегодня» берётся из локального времени, а не из `toISOString()`, иначе в часовых поясах восточнее UTC день сдвигается.
2. Сетка в `LegacyBoardStats.module.css`: 4 колонки, до 899px — 2×2, до 639px — одна колонка.
3. Тесты в `App.test.tsx`: дублёр репозитория с состоянием и подмена только `Date` (`vi.useFakeTimers({ toFake: ['Date'] })`). Таймеры не подменяются, чтобы работал `userEvent`.

### Что могло измениться или сломаться
- **Пока задачи загружаются, все счётчики показывают 0.** Раньше значения сразу читались из `localStorage`.
- **Испорченные данные в `localStorage`.** Статистика теперь зависит от того, что вернёт репозиторий. Если он восстановил пример, показатели считаются по примеру, а не по нулям, как раньше.
- **Смена суток.** «Сегодня» вычисляется при рендере. Если вкладка открыта через полночь, счётчик изменится только при следующем действии с задачами.
- Имя `LegacyBoardStats` оставлено намеренно, чтобы не расширять дифф. Переименовать компонент можно отдельным PR.
